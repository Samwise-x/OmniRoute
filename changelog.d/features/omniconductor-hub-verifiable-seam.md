- **feat(conductor):** the Omniconductor Hub is now provable rather than asserted — `npm run verify:conductor` boots real Hub/Faro/Runner processes and writes a GO/NO-GO report to `docs/ops/OMNICONDUCTOR_EVIDENCE.md`, `npm run verify:conductor:docker` builds and brings up the Compose stack on a Docker host (and fails loudly where there is no engine), plus `test:conductor:contract` drives OmniRoute's production route handlers against a real Hub. New `tests/unit/conductor-runtime-guards.test.mjs` (10 cases) and `tests/unit/conductor-opencode-seam.test.mjs` (6 cases) cover the refusal, isolation and harness-contract paths that had none, and a `OmniConductor Hub (runtime evidence)` CI job runs all of it.
- **fix(conductor):** four defects a live deployment exposed and no test caught. The Agent Card advertised **no fleet at all** — `fleetSkills` required `models: [{id}]` while the bundled Hub sends plain strings, so the whole skill list was dropped; the Runner invoked **`opencode run --auto`**, a flag the released CLI does not have, and handed it no gateway config (its per-task HOME is empty), so self-hosted OpenCode fell back to its own hosted catalog; a `<prefix>/*` capability such as `omniroute/*` was compared as a literal string, leaving every gateway-pinned task queued forever; and a task whose CLI/model a Runner could not serve threw outside the error handler and killed the Runner process instead of failing that one task.
- **feat(conductor):** OpenCode is the reference self-hosted harness for the Runner seam. With `OMNIROUTE_BASE_URL` set the Runner seeds a per-task `opencode.json` whose only provider is the operator's gateway, with the key referenced as `{env:OMNIROUTE_API_KEY}` so it is never written to disk, the workspace or the patch; `OPENCODE_MODEL` supplies the default `--model`, and a bare (non-`omniroute/`) model is refused unless `RUNNER_OPENCODE_ALLOW_HOSTED_MODELS=true`, so a self-hosted deployment cannot silently route work to OpenCode's catalog.
